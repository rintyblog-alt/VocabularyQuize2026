`client/v2/ui/ai-activity.js` の Timeline / Panel。
Quick Mock とプリセット作成の右側（狭い画面では下から引き出すシート）に出る。

2026-08-04 に **Claude Code の出し方へ寄せた**。

---

## 1. 何を変えたか

| | 前 | いま |
|---|---|---|
| 1 件の形 | 枠つきのカード | 1 行（見出し）＋ ⎿ でぶら下げた結果 |
| 1 行の高さ | 90px 前後 | **中央値 46px** |
| 左の印 | 26px の丸＋種類アイコン | 7px の丸（状態の色だけ）。種類は見出し前の小さなアイコン |
| 時刻・所要 | 普通の数字 | 等幅の数字（行ごとに幅が揺れない） |

```
● 📄 資料を読み取りました                    11秒
  ⎿ 3 件・42 ページ / 12,480 字
● ✨ 大問1 を作っています（8 問・25 点）    2分23秒
  ⎿ 3 問ずつに分けて頼みます
● ✓ 大問1 に 8 問入りました                13:24:41
  ⎿ 合計 8 / 30 問
◐ ⚠ 正誤問題の正解がどちら側か分かりま…    13:24:41
  ⎿ この枠は空のままにします。当てずっぽうで正解を決めません。
```

**色は状態だけに使う。** 緑＝終わった／橙＝注意／赤＝失敗／灰＝これから。
種類（資料・作成・検証…）はアイコンの形で分ける。
種類ごとに色を塗ると、10 件並んだとき「いまどれが動いているか」が読めなくなる。

## 2. 狭い画面で崩れないための決まり

`node vqlogui.cjs` が 320px まで見張っている（20 件）。

- **横スクロールを作らない。** 長い語は `overflow-wrap: anywhere` で途中で折る。
  英語のエラーコード（`INSUFFICIENT_EVIDENCE_evidence_gate_rejected_…`）でも折れる。
- **見出しは 1 行で切る**（`text-overflow: ellipsis`）。折り返して 3 行になると一覧として読めない。
  全文は「詳細を見る」で読める。
- **「詳細を見る」は狭い画面で 44px 以上。** 広い画面では 28px（マウスなら足りる）。
- ⎿ の印は `aria-hidden`。読み上げには出さない（飾りなので）。

## 3. さわるときの注意

- **クラス名を変えないこと。** `vq2-tl-i` / `vq2-tl-t` / `vq2-tl-s` / `vq2-tl-node` /
  `vq2-tl-more` / `vq2-tl-d` / `vq2-tl-dl` は既存の E2E が名指しで探している
  （`vqtl.cjs` / `vqactvis.cjs` / `vqaiux.cjs` / `vq2studio.cjs` / `vqpresetai.cjs`）。
- 種類は `KINDS`（13 種）から引く。**知らない種類は info へ落ちる**ので、
  新しい行を足すときは KINDS にある名前を使うこと。
  `step` / `note` / `done` のような独自の名前を渡すと、全部同じアイコンになる。

## 4. 確かめ方

```bash
node vqlogui.cjs     # PC / 390px / 320px で高さ・はみ出し・タップ領域（AI 不要）
node vqtl.cjs        # タイムラインの中身
```
