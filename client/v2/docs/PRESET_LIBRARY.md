# プリセットの一覧と詳細

「自分のもの」「ほかの人の公開」「VocabuQuiz公式」の 3 つを、
**同じ形で並べて、見て区別できるようにする**ための作り。

---

## 1. なぜ作り直したか（前の版で起きていたこと）

| 症状 | 本当の原因 |
|---|---|
| カードの上が大きな空白 | 表紙を一度も読んでいなかった。`qcImg()` が http(s) しか通さず、`x.banner` は誰も入れていなかった |
| 自分のもの以外が全部「公式」 | `official = (kind !== "mine")` と決め打ちしていた |
| `summarize 1・choice_many 1` と出る | 形式の内部 ID をそのまま表示していた |
| `sub:english` と出る | 科目の内部 ID をそのまま表示していた |
| 「0 で全 N 問」「0 でなし」 | 数字に隠れた意味を持たせていた |

## 2. どこから来ているデータか

一覧の出どころは **本体のライブラリ画面（`#appLibraryPage`）だけ**。
開始・編集・削除・複製はすべてそこのボタンへ `.click()` で渡すので、
**そこに出ているものだけが「いま本当に始められるもの」**になる。

```
#appLibraryPage の .app-library-item
   ↓ scrapePresets()   … 出ている情報をそのまま写す（何も判断しない）
   ↓ VQ2.library.collectDom()
        ├ fromScraped()  … 種別・作者・アイコン・件数を 1 つの形にそろえる
        └ この端末の保存（VQ2.store）から、画面に出ていないものを足す
              （形式の内訳・説明・表紙・目安の時間）
   ↓ applyFilters → sortList → sections
   ↓ カード（vq-screens の中）
```

### 種別は「本体が付けた印」だけで決める

`data-kind` が `official` / `builtin` / `mine` / `public` のどれか。
**名前や作者名からは決めない。**

| data-kind | 画面での見え方 |
|---|---|
| `official` | VocabuQuiz公式（配信） |
| `builtin` | VocabuQuiz公式（収録） |
| `mine` | マイプリセット＋公開中／非公開 |
| `public` | 公開（作者名つき） |

`isOfficial` / `isOwnedByCurrentUser` / `visibility` は**別々に**持つ。
自分が公開したものは「マイプリセット」であり「公開中」でもある。

## 3. 表紙とアイコン

**絵は作らない。** 表紙の画像を持っているプリセットは 1 つも無いので、
科目の色（`--lib-hue`）と控えめな模様だけで埋める。同じプリセットには必ず同じ色が出る。

```
--lib-hue   … 科目 + ID のハッシュ（library.fallbackBanner）
--lib-l1/l2/l3 … 明るさ。ダークで差し替える
```

影の DOM の中からは `html[data-theme-mode]` を選べないので、
明るさは**外側（`#vqScreens` / `:host`）で決めて変数として渡す**。

アイコンは 画像 → 本体が付けた記号（Material Symbols の名前）→ 題名の頭文字 の順に落とす。
壊れた画像は出さない（`onerror` で消す）。

## 4. 画面に出す言葉

内部の ID は 1 つも出さない。必ずこの 3 つを通す。

| 出したいもの | 使う関数 |
|---|---|
| 科目 | `library.subjectLabel(subject)` |
| 形式の内訳（1 行） | `library.typeSummary(counts, 3)` → 「4択・要約・多肢選択」 |
| 形式の内訳（一覧） | `library.typeBreakdown(counts)` → 「4択 3問」… |

形式の名前の出どころは `VQ2.qtypes` だけ（`[[QUESTION_TYPES_V3]]`）。

## 5. 一覧

- タブ 5 つ … すべて / マイプリセット / 公開プリセット / 公式 / お気に入り（件数は実数）
- 検索（名前・科目・作者・タグ）・科目チップ・並べ替え 7 通り・カード / 一覧の切り替え
- 「すべて」で、絞り込みも並べ替えもしていないときだけ区切って見せる
  （最近使った → マイ → 公式 → 公開）
- 並びは `repeat(auto-fill, minmax(min(100%,280px), 1fr))`、最大 1500px
- 選んだ状態は URL に残す（`lib_tab` / `lib_subject` / `lib_sort` / `lib_q` / `lib_view`）
- 読み込み中は形だけ置く。6 秒待っても来なければ「まだ読み込めていません」と正直に出す
  （**0 件と言い切らない**）

## 6. 詳細

PC は中央のカード（1000px まで）、スマホは下から出る全画面。
操作は常に下に固定する。

- 上：表紙 → アイコン → 名前 → 種別 → 作者
- このプリセット：科目・問題数・目安の時間・タグ・公開範囲・最終更新（**無い行は出さない**）
- 問題の内訳：日本語の名前と本数
- 解きかたを決める：モード / 出題数 / 1 問あたりの時間 / 全体の制限時間
  すべて選ぶ形にして、「0 で全問」のような書き方はしない
- ほかにできること：**本体にボタンがある操作だけ**出す（`__vqPresets.can(card, key)`）

`__vqPresets` から引ける。

```js
window.__vqPresets.cards()        // いま並んでいるカード
window.__vqPresets.card(id)       // 1 枚
window.__vqPresets.can(card, key) // その操作ができるか
window.__vqPresets.action(id, key)// open|start|write|edit|remove|publish|unpublish|share|fork|profile
```

## 7. 公開する（モーダル）

`client/v2/ui/preset-publish.js`（`VQ2.presetPublish`）。

これまでは 5 画面のウィザードだった。決めることは 4 つしか無いので、**1 枚にまとめた。**
上に「公開したらこう見える」を出し、名前・アイコン・色を触るたびにそこが変わる。

残した項目：公開ID（重複の確認つき）・公開するときの名前・アイコン・色・注意事項と同意。

- すでに公開しているものは「変更を保存」＋「公開をやめる」になり、**同意のやり直しは求めない**
- 公開が終わると、リンクをコピーできる
- **通信と保存はアプリ側が持ち主。** ここは見せ方だけを受け持つ

### アプリ側の受け口（`window.__vqAppData`）

新しい画面が必要とするものだけを、アプリから 1 か所で渡している。
二重に実装すると、認証の付け方と保存先がずれる。

```js
window.__vqAppData.me()                       // 表示名・@ID・アイコン・ログイン状態
window.__vqAppData.publicPresetById(presetId) // 公開一覧が持っている作者の情報
window.__vqAppData.publish.{
  available, reason, icons, colors, meta, suggestSlug, validateSlug,
  checkSlug, previewLink, submit, unpublish, openLegacy
}
```

`openLegacy` はこれまでの全画面フロー。新しい画面が使えないときの逃げ道として残してある。

### カードの作者表示

公開しているものは、**公開先で見えるのと同じ名前・@ID・アイコン**をカードに出す。

| 状態 | 出るもの |
|---|---|
| 自分のもの・非公開 | 「自分が作成」 |
| 自分のもの・公開中 | アイコン ＋ 表示名 ＋ @ID ＋「自分」 |
| ほかの人の公開 | アイコン ＋ 表示名 ＋ @ID |
| 公式 | VocabuQuiz（配信 / 収録） |

**内部の番号（user_id）は出さない。** 出すのは `@` から始まる公開用の ID。

## 8. 形式を選ぶモーダル

形式は 130 種類ある。**一度に全部を平らに並べない。**

- 上に「探す」と見かた（すべて / おすすめ / 最近使った / よく使う）を固定
- 左に分類（数つき）、右に結果。**右だけがスクロールする**
- カードの札は「他と違うところ」だけ（AI / 部分点 / 画像・音声）。
  全部に同じ札が並ぶと読む手がかりにならない
- 矢印キーで隣のカードへ動かせる
- 描き直しても、読んでいた位置は動かさない
- スマホは分類を上に横並び、結果は 1 列
