# VocabuSurvive — 探索モード（RPG）実装計画

訴え（2026-09-02 02:15、Rinty さん）:
> ロビーの UI から ゲームの UI、さらには ゲーム性まで。
> 今の アスレチック以外にも、RPG ゲーム（探索ゲーム）とか 作るといい。
> 長い物語が あって、アイテムも 膨大。敵も いて マップも 巨大。
> マテリアルを 最高級品質に したいが、スマホ・パソコンで 重くならないように。
> クラフトとかも できて、素材も 集められるように。建物も あって、
> 自分で 建物を 建てたりも できるように。種類も 膨大に。

## 芯（ここを 外さない）

1. **これは VocabuQuiz の 中の ゲーム。** 語彙を 解くことが 強さに 直結する。
   ただ 走るだけ・ただ 殴るだけの RPG には しない。
2. **重くしない。** スマホで 30fps を 下回らない。
   絵の 質は「多く 描く」ではなく「**同じものを まとめて 描く**」で 上げる。
3. **止まらない。** 巨大マップは 区画（チャンク）で 出し入れする。
   1 フレームに 作る 量に 上限を 置く。
4. **無いものを 在るふりに しない。** 作れて いない ところは 画面に 出さない。

## 作り

```
rpg/
  world/    地形・区画・生成・木や岩の 置きかた
  data/     アイテム・作りかた・敵・建物・物語（表だけ。ふるまいは 持たない）
  sys/      持ちもの・作る・戦う・建てる・依頼・保存
  ui/       HUD・持ちもの窓・作る窓・建てる窓・会話
  screen.js 画面（shell へ register する）
```

engine/（renderer・mesh・camera・particles）は **そのまま 使う**。
描き手を もう 1 つ 作らない。
