# _fixtures — 検査が 使う 見本

検査の いくつかは 「読み取りに かける 画像」や 「作りかけの 資料」を 要る。
前は **その ときの 一時フォルダの 絶対パス**を 既定に していたので、
セッションが 終わると 二度と 動かなく なった（2026-09-06 に 23本 で 実測）。

いまは ここが 既定。中身は git に 入れない（大きい・使い捨て）。

    _fixtures/pages/   … 読み取りに かける 画像（PNG / JPG）

環境変数で 別の 場所も 指せる:

    VQ_PAGES=/どこか/pages node vqocrbench.cjs
