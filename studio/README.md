# VQ Studio — ブラウザだけで動く動画編集ソフト

CapCut / Premiere のような編集ソフトを **インストール無し・サーバ処理なし**で動かす。
素材はあなたの端末から出ない（保存も書き出しも全部ブラウザの中）。
さらに **プロンプト 1 行から動画を組み立てる自動編集**を載せてある。

```
開く: https://vocabuquiz.app/studio/
    ?debug=1   … 内部のログを出す
    ?new       … 起動と同時に新規プロジェクト
    ?project=<id> … 指定のプロジェクトを開く
自己診断: /studio/selftest.html  … この端末で何が動くかを一覧で出す
```

## 1. できること

### 編集の土台
- **多トラック**（映像 / 音 / オーバーレイ（文字・図形・PiP）/ 調整レイヤー）
- クリップの移動・トリム・**分割**・複製・詰めて削除（リップル）・グループ化・複合クリップ
- **吸着**（再生ヘッド・クリップの端・マーカー・**音楽のビート**）と磁着
- 取消／やり直し（120 手）、コピー／貼り付け、マーカーと章
- タイムラインのズーム（ホイール／ピンチ）、全体表示、ミニマップ、フィルムストリップ、波形
- ツール: 選択 / リップル / かみそり / 手のひら

### 見せ方
- **変形**（位置・拡大・回転・反転・基準点・クロップ）と**キーフレーム**
  （property ごとの独立チャンネル・イージング・ベジェ編集）
- **速度**（0.1〜10 倍・尺を保つ/伸ばす・逆再生・フリーズ・**速度カーブ**）
- **遷移 30 種超**（クロスフェード・ディップ・スライド・押し出し・ワイプ・虹彩・
  ぼかし溶解・ホイップパン・ズーム・グリッチ・光漏れ・フィルムバーン…）
- **効果 30 種超**（ぼかし各種・シャープ・モザイク・ポスタライズ・輪郭・魚眼・
  歪み・色収差・グリッチ・VHS・走査線・粒子・ビネット・ブルーム・ネオン・鏡像…）
- **カラー**: 露出・コントラスト・彩度・色温度・色合い・ハイライト/シャドウ・白/黒・
  自然な彩度・カーブ（RGB/R/G/B/輝度）・カラーホイール（リフト/ガンマ/ゲイン/オフセット）・
  HSL 個別・**.cube の LUT 読み込み**と内蔵 LUT・プリセット
- **スコープ**（ヒストグラム / 波形 / ベクトル）で白飛び・黒潰れを確かめられる
- **マスク**（矩形・楕円・多角形・直線・放射／ぼかし・反転）と**クロマキー**（緑背景抜き）
- **ブレンドモード**と不透明度
- **文字（テロップ）**: 書体・寸法・縁取り・影・発光・グラデ・背景・様式プリセット・
  入り/出/ループの**アニメ**（文字単位・単語単位・行単位）・SRT/VTT の読み書き

### 音
- クリップごとの音量・フェード・パン・ミュート・**音を分離**
- トラックの**ミキサー**（フェーダー・パン・ソロ/ミュート・メーター）
- 音の効果: EQ・コンプレッサ・ゲート・リミッタ・リバーブ（内部生成）・ディレイ・
  ローパス/ハイパス・ステレオ拡張・ディエッサ・歪み
- **BGM の自動ダッキング**（声の上で音楽を下げる。キーフレームで表現するので後から直せる）
- 音量そろえ（−14 LUFS 目安）、アフレコ（マイク録音）

### 自動編集（AI）
- **プロンプトから組み立てる**: 「旅行の動画を 30 秒のテンポいい Vlog に。テロップ入れて、
  BGM のビートで切って」→ 素材を解析 → 構成を考える → タイムラインを作る
- ネットが無い / API が落ちていても **端末の中だけで**組み立てる（決定論の設計）
- 追い注文（「もっとテンポ速く」「テロップ大きく」「最後を 5 秒短く」）
- テンプレート: 旅行 Vlog / 商品紹介 / 解説 / ショート縦 / ダイジェスト / シネマ / 他
- 「自動」道具: **無音カット** / ビート同期 / **自動リフレーム（9:16 追従）** /
  自動カラー / 音量そろえ / BGM ダッキング / ハイライト抽出 / 章を作る /
  ズームパンチ / 遷移の自動付け / 字幕の枠づくり
- 素材の解析: ショット境界・動きの量・ピント・明るさ・彩度・手ぶれ・
  音量包絡・無音区間・声らしさ・**BPM とビート位置**

### 書き出し
- **動画**: mp4（H.264）/ webm（VP9）。
  - **高精度（WebCodecs + 自前 muxer）** … フレームを 1 枚ずつ確実に出す
  - **実時間（MediaRecorder）** … 速いが近似（iPhone では使えないので自動で高精度に）
  - 解像度・fps・画質・範囲（全体/イン〜アウト）・音声の有無
- **静止画**（PNG/JPEG・連番）、**音声**（wav/webm）、**GIF**（自前エンコーダ）
- **字幕**（SRT / VTT）、**プロジェクト**（.vqstudio ＝ 素材ごと持ち出せる）、EDL の JSON
- プリセット（YouTube / Shorts / TikTok / Instagram / X / 4K / 軽量 / 音声のみ …）

### アカウント
VocabuQuiz の会員基盤をそのまま使う（**同じアカウントで入れる**）。
- 新規登録 → **メールに 6 桁の認証コード** → 暗証番号（任意）→ 規約同意
- ログイン（学年 + ニックネーム + パスワード）／ログインしたまま
- パスワード変更・パスワード再設定（コード or 暗証番号）
- **ゲストで試す**（ログインしなくても機能制限なし。保存はこの端末の中だけ）

### モバイル
CapCut の作法に寄せてある。
- プレビュー上・タイムライン中・**下段タブ**（編集/オーディオ/テキスト/ステッカー/
  オーバーレイ/エフェクト/フィルター/比率/自動編集）
- クリップを選ぶと**文脈ツールバー**（分割・削除・複製・速度・音量・アニメ・
  不透明度・クロップ・回転・反転・逆再生・フリーズ・マスク・カラー・効果・遷移…）
- 数値は**ボトムシート**の大きなスライダー（中央スナップ付き）
- ピンチでタイムラインの拡縮、長押しで並べ替え、端の白いハンドルでトリム
- 触り所は 44px 以上、safe-area 対応、100dvh

## 3. この端末で動くかどうか

`/studio/selftest.html` を開くと、読み込みと最小限の動作が一覧で出る。
主な前提:

| 機能 | 必要なもの | 備考 |
|---|---|---|
| プレビューの色補正・効果 | **WebGL2** | 無い端末は簡易描画（変形・不透明度・文字まで） |
| 高精度の書き出し | WebCodecs `VideoEncoder` | Safari 16.4+ / Chrome 94+ |
| 書き出しの音 | `AudioEncoder` | **Safari は 26 以降**。無い場合は無音動画＋wav を別に出す |
| 実時間の書き出し | `canvas.captureStream` | **iPhone/iPad には無い**（自動で高精度に切り替える） |
| 素材の保存 | IndexedDB | 使えない環境では一時保存（再読込で消える） |
| 触覚（振動） | `navigator.vibrate` | iOS には無いので画面の合図で代える |

> iOS の Safari は、しばらく使わないと保存データを消すことがある。
> 大事な作品は **プロジェクトを書き出して**（.vqstudio）手元に持っておくこと。

## 4. 作りの話（開発者向け）

- 設計の契約は [`ARCHITECTURE.md`](./ARCHITECTURE.md)。**データ構造と全 API はここが正**。
- 依存の向きは `ui → ai → analysis → engine/export → core`。core は誰にも依存しない。
- ビルド無し。`<script type="module">` から `src/main.js` だけを読む。外部依存ゼロ。
- 保存形式は 1 つ（`Project` の JSON）。素材の実体は IndexedDB、参照だけが JSON に入る。
- 編集は **全て `core/ops.js` の op を通る**（UI も AI も同じ道）。だから取消が効く。
- 端末ごとの差は `core/caps.js` が 1 箇所で調べる（画素で試す・UA で決めない）。

### 試験

```sh
cd studio && npm test                  # 純ロジックの単体試験（node --test）
node tests/e2e/selftest.mjs            # ブラウザで自己診断（要 playwright）
node tests/e2e/editor.mjs              # 通し試験（取り込み→編集→AI→書き出し）
node tests/e2e/export.mjs              # 書き出しが本当に再生できるか
node tests/e2e/color-probe.mjs         # 動画のフレームが画面に出ているか（色で確認）
node tests/e2e/clock-probe.mjs         # 再生の時計が実時間どおりか
```
