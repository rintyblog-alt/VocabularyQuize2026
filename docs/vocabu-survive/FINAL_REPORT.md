## 1. できたこと

左パネル → 読み込み画面 → **START** → ロビー → 試合 → ゴール → 結果 まで、
**実際に 遊べる 状態**で 本番に 出ている。

| こと | 中身 |
|------|------|
| 入口 | 左パネルの 1 つ。**押すまで 1 バイトも 読まない** |
| 読み込み画面 | 題字・立体の キャラクター・START・進み・版 |
| ロビー | コース 30 本／難しさ 7 段／遊び方 4 つ／色 8 つ／人数／友だち／招待 |
| 試合 | 最大 8 人。合図 → 走る → 仕掛け → クイズの門 → 中間地点 → ゴール |
| コース | **30 本**。1 本ごとに 「そこでしか 出ない 判断」を 持たせた |

| 操作 | 鍵盤／マウス／指の 操作盤（棒は 押した 場所に 出る） |
| 端末 | 机の上・スマホ 縦/横・タブレット。セーフエリア対応 |
| 通信 | 最大 8 人。**サーバが 正**。切れても 続く・戻れる |
| 友だち | 相互フォローの 人を 通知で 誘える。押すと そのまま 部屋へ |
| 成績 | 試合数・勝ち・XP・正答率・自己ベスト・コースの 上位 |
| 音 | **音源ファイル 0**。WebAudio で その場で 作る |

## 2. 組み立て

```

  ui/       影の DOM（本体の 1.4MB CSS と 一切 ぶつからない）
  net/      WebSocket・先読み・補間
  data/     コース 30 本・控えの 問題 80 問
```

別々に 書くと 「検査は 通るのに 遊ぶと 詰む」が 必ず 起きる。

## 5. 検査が 見つけた **本当の 不具合**（すべて 直した）

### 走る人
1. 跳びの 削りが **全部の 上向き**に 効いていた
   → トランポリンが 4.8m の はずが **1.79m**。毎フレーム 9% 削られていた
2. 弾きの 向きが 逆（押し出す 法線に − を 付けていた）→ 直後の 押し戻しで 速さが 0 に
3. 弾きが 「足すだけ」→ 8.2m/s で 突っ込むと +9 を 足しても 0.8 しか 残らない
4. 段差を 上る 仕組みが 無く、高さ 0.2m の トランポリンの 横で 足が 止まっていた

### コースと 仕掛け
5. 時間の 門が **実質 0.13 秒**しか 開いていなかった（duty 0.34 なのに 開閉に 0.14 ずつ）
6. ローラーが 床から 2m せり上がり、跳びの 高さと 同じ＝**越えられない 壁**
7. 消える 板の 間が **7.8m**（跳べるのは 5.88m）
8. 細い 道の 継ぎ目が 粗く、板の 間に **穴が 空いていた**
9. 落ちる 板の 横ずれが 6.8m ＝ 前後と 合わせて **7.7m**
10. 幅 1.5m の 道の 上に 回る 棒（避ける 場所が どこにも 無い）
11. 滑る 床の 上の バンパーに 壁が 無く、弾かれたら 必ず 落ちる
12. 消える 板の 重なりが 1.44 秒 しか なく 渡り切れない
13. neon と arena の 床が 暗すぎて **足元が どこか 分からない**

### 通信・安全
14. **最初の 1 通を 弾いていた**。出発の 並びは 横へ 最大 ±7m ずれている のに
    サーバは 0 を もとに 速さを 見ていた
15. `/api/survive/questions` が presetId を **user_id で 絞らずに** 引いていた
    （動いて いたら 鍵を 当てるだけで 他人の 単語帳を 読めた）
16. `/api/survive/friends` が **存在しない 表**を 引いていた（友だちは 必ず 0 件）
17. `/api/survive/*` が **flag の 関所より 先**に あり、機能を off にしても URL 直打ちが 通った
18. 部屋の 作りすぎに 制限が 無かった

### 画面
19. 隠れている 間に 板を 1×1 に 縮めていた（戻ると 1 コマ 潰れた 絵）
20. 本体の 下の 帯が 跳ぶ ボタンを 覆っていた（横向きでは 高さの 17%）
21. やめる ボタンが 4 隅の どこに 置いても 何かと 重なった
22. クイズの 札が スマホで 1 列に なり、縦に 伸びて 跳ぶ ボタンまで 覆っていた
23. **人どうしが すり抜けていた**（走る人が 重なって 1 人に 見える）
24. ボットが 全員 中心線を 追って **団子に なっていた**

### 検査 自体の 誤り（直さないと 誤った 判断を する）
25. 「どこまで 行けたか」を **最後の 位置**で 見ていた（落ちた 直後は 出発点）
26. クイズの 門の 幕（床から 4.6m）を「足場」と 数え、全 30 本で「段差 4.6m」と 出ていた
27. バンパーの 頭を「足場」と 数えていた
28. esbuild の 逃がし方は **大文字の 16 進**（チ）。小文字で 探して 見つからなかった

## 6. 残っている こと

### コースの 走り 検査 27/30
`vqsurvivegap`（形の 検査）は **30 本 すべて 合格**。
隙間・段差・板から板 の どれも 跳べる 範囲に ある。
残る 3 本（c12 崩れる橋 / c17 三又の選択 / c29 最後の試練）は
**コースが 無理なのでは なく ボットの 腕**。
実際 c12 は 種を 変えると 21 秒で 通る（8 回中 1 回）。

苦手の 中身:
- 消える 板を 続けて 渡る とき、2 手 先まで 読めていない
- 3 本の 道が 並ぶ とき、どの 道を 選ぶかを 決めきれない

### そのほか
- 影を 毎フレーム 焼き直している（動かない 仕掛けが 多い コースで 無駄）
- 部屋の 作りすぎの 見張りが isolate の 中（消えると 数え直し）
- チーム戦・勝ち抜きは 未実装（レースの 出来を 落としてまで 増やさない）
- 走る人の 見た目の 着せ替えは 未実装

## 7. 決めたことの 要点

| 決めた こと | 理由 |
|-----------|------|
| 3D は **自前 WebGL2** | Babylon.js 4.5MB は 細い回線（実測 1.2Mbps）で 30 秒。
  旧 v1/v2 は その Babylon が **どこにも 無く 起動不能**だった |
| 音は **その場で 作る** | 著作権の 心配 0・落とす量 0 |
| 中身は **影の DOM** | 本体の 1.4MB CSS と 一度も ぶつからなかった |
| 束は **1 本＋指紋** | 素の まま 40 本 配ると 細い回線で 数秒 |
| サーバは **検算だけ** | 8 人 × 60Hz の 物理を DO で 回すのは 高い。
  速さ・瞬間移動・順番・ゴール・答え を 見れば 十分 |
| 旧 VocabuSurvival は **触らない** | 別物。継ぐより 建てる ほうが 速く、既存も 壊さない |
| 出し方は **既存のまま** | `server/` から `npx wrangler deploy` 1 本 |
