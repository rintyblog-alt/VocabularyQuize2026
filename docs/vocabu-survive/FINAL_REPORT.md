## 2. 大きな 決めごと（なぜ そう したか）

### ① 3D の 部品を 借りない

Babylon.js は 4.5MB。細い 回線（実測 1.2Mbps）で 30 秒 かかる。
**旧 v1/v2 は これで 死んでいる。**
自前で 書いた 結果、束は **327KB（圧縮 101KB）**。

### ② 影の DOM に 閉じ込める

本体の CSS は 1.4MB ある。`attachShadow` で 中に 入れて、
外から `display:none` を 掛けても 中は 無事な ことを 検査で 固定した。

### ③ サーバで 物理を 回さない

8 人 × 60Hz を Durable Object で 回すのは 高い。
代わりに **「あり得るか」だけ 見る**（速さ・瞬間移動・中間地点の 順番・
ゴール・クイズの 答え）。答えは サーバが 持ち、画面の 申告は 使わない。

### ④ 音源ファイルを 置かない

著作権と 落とす量。その場で 合成すれば **0 バイト**。

### ⑤ 決まった 歩（60Hz）＋ 補間

走りは いつでも 同じ。描くのは その 間を 埋めるだけ。
`Math.random` も `Date.now` も 走りの 中では 使わない。

## 5. 途中で 見つけて 直した もの（抜粋）

作り話では なく、**すべて 検査か 実写で 見つけた もの**。

| 何 | 真因 |
|----|------|
| 画面が 真っ白 | タブが 2 回 効き、器を 空に した あと open() が 早戻りしていた |
| **アプリの どこにも 移れない** | localStorage が いっぱい／使えない ときに むき出しの setItem が 投げていた |
| 跳べない コースが 3 本 | 中間地点を **足す**と 8m ずれ、時間で 動く 仕掛けの 位相が 変わる |
| スマホで 色も 帽子も 選べない | 1080px 以下で 左の 箱を まるごと 消していた |
| 箱が 6px はみ出す | 並べ枠の 中の 箱は 既定で min-width:auto |
| 他人の 単語帳が 読めた | user_id で 絞らずに 引いていた（しかも 列名が 違い 常に 失敗） |
| Ban が 効かない | この 引き受けが 本体の 関所より 先に あった |
| トランポリンが 跳ねない | 跳びの 打ち切りを **すべての 上向き**に 掛けていた |
| バンパーに 押し込まれる | 弾く 向きが 逆で、めり込み 直しが 速さを 消していた |
| ボットが 崖で 止まる | 先の 板を「地面」と 見て 隙間へ 走り込んでいた |
| 「ずっと 詰まっている」 | 検査が **最後の 進み**を 見ていた（最高到達では なく） |
| 帯が 画面を 横切る | 縦積みの 箱の 中で 幅が 伸びていた |
| 暗い 風景の 札が 押せなく 見える | 風景の 色を 枠に 使っていた |
| うすい 文字が 読めない | 明暗 4.49:1（要 4.5:1）。半透明の 背景を 重ねて 測って 初めて 分かる |
| 上位表が 作り物で 埋まる | ひとりの 記録は 自己申告。長さを 覚えて 「あり得ない 速さ」を 外した |

## 7. 触り方（開発）

```bash
# 束ねる（client/assets/vocabu-survive/**.js → client/js/vq-survive.<指紋>.js）
node vqsurvive.cjs

# ローカルで 丸ごと 動かす
cd server && ./dev-local.sh echo 8795

# 検査（どれも 本番では 走らない ように 先頭で 止める）
node vqsurvivecourse.cjs      # 30 本 走らせる（いちばん 長い）
node vqsurvivegap.cjs         # 形だけ 測る（速い）
node vqsurviveaudit.cjs       # 最終監査
node vqsurvivehard.cjs        # 意地の悪い 場面

# 本番へ
cd server && npx wrangler deploy
node vqsurviveprod.cjs        # 出したあとの 煙（読み取りだけ）
```

書類: `ARCHITECTURE.md`／`NETWORKING.md`／`PERFORMANCE.md`／`COURSES.md`／
`EDITOR.md`／`DECISIONS.md`／`ROADMAP.md`／`PROGRESS.md`

## 8. いちばん 大きかった 収穫

**検査を「意地の悪い 場面」まで 広げた こと。**

`vqsurvivehard` を 書いた その 日に、
**localStorage が いっぱい／使えない 端末では アプリの どこにも 移れない**
という 不具合が 出た。VocabuSurvive の 話では なく、
アプリ 全体の 入口が 塞がる もので、
ふつうに 遊んで いる 限り 絶対に 気づけない。

「動く ことを 確かめる」検査より、
**「壊れた ときに どう なるか」を 確かめる 検査**の ほうが 見つける。
