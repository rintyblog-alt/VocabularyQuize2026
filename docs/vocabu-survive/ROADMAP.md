## 覚えておく こと（つまずいた ところ）

### yaw は「カメラの ある 側」を 指す

進む向きは **-(sin yaw, cos yaw)**。脚も つま先も 体の 傾きも そちら側へ 出す。
`bean.js` の 顔（目・帯・芽・かぶりもの）だけ 逆の +(sin, cos) 側に 置いていた ため、
**全員 ずっと 後ろ向きに 走って いた**（進む向きと 顔の向きの 内積が -1）。
`vqsurviveface.cjs` が 描く 命令を 横取りして 数で 見張っている。

見せる 場面（ロビーの 舞台・読み込み画面）は **こちらを 向いて ほしい**ので、
draw に 渡す yaw へ `Math.PI` を 足す。ここを 忘れると 背中しか 見えなくなる。

### 影の DOM でも 本体の トークンは 届く

`:host{ all: initial }` でも **カスタム プロパティは 消えない**（実測）。
だから 色・角・字は `var(--vq-*)` を そのまま 引ける。本体の 明暗・アクセント色・
角の 丸みの 設定が この 画面にも 効く。逃げ道（第 2 引数）は 必ず 付ける。

`_drawerShareGetDb("read")` のような「開発では 塞がる 口」を うっかり 使うと、
手元と 本番で 見える ものが 変わる。
