## 次に やる（優先順）

遊べない ところは 残っていない。下は どれも「あると 良い」もの。

### ① スマホでの 立体の 置き方
指 1 本で 見回し・2 本で 寄り引き までは 入っている（車輪と 同じ 口）。
つまんで 動かす（ドラッグで 位置を 直す）は まだ。

### ② 影の 焼き直し
動かない 仕掛けが 多い コースでは 毎コマ 焼き直すのが 無駄。
ただし 実測 1.9ms で 困っていないので 急がない。

### ③ みんなの コース（公開の 棚）
いまは 合言葉で 手渡し。公開の 棚に 並べるには
「消す・直す・報告する」を 作らないと いけない。急がない。

### ④ そのほか
- 勝ち抜き・ゴーストが ひとり用だけ（対戦は 作りが 大きく 変わる）
- 音の 合成が メインスレッド（実測では 問題なし）

## やらない ことに した

| こと | 理由 |
|------|------|
| Babylon.js / three.js を 借りる | 4.5MB。細い 回線で 30 秒。旧 v1/v2 が これで 死んでいる |
| 音源ファイルを 置く | 著作権と 落とす量。その場で 作れば 0 バイト |
| サーバで 物理を 丸ごと 回す | 8 人 × 60Hz を Durable Object で 回すのは 高い。「あり得るか」の 検算で 十分 |
| 旧 VocabuSurvival を 継ぐ | 別物（2D 横スクロール中心）。継ぐより 建てる ほうが 速く、既存も 壊さない |
| 対戦で 自分の 単語帳を 使う | 相手の 端末から 引けない。自分だけ 自分の 単語・相手は 内蔵に なり、同じ 勝負に ならない |
| かぶりものに 性能を 付ける | 「この 帽子が 強い」に なり、全員 同じ 帽子に なる |
| 中間地点を **足して** 増やす | 8m ぶん 後ろが ずれ、時間で 動く 仕掛けの 位相が 変わって 3 本 通れなく なった（実測 27/30）。飾りの 無い PW を その場で 置き換えるなら 形が 変わらない |
| 勝ち抜きを 対戦でも | 部屋が 1 試合で 終わる 作り。無理に 通すと レースの 通信まで 危うく する |
| ゴーストを 対戦でも | 半透明の 自分が もう 1 人 いると、どれが 相手か 分からなく なる |
| 飾りに 新しい 形を 足す | 並べ描きの まとまりが 割れて 描き回数が 増える。置き方だけ 変える |
