## やらない ことに した

| こと | 理由 |
|------|------|
| Babylon.js / three.js を 借りる | 4.5MB。細い 回線で 30 秒。旧 v1/v2 が これで 死んでいる |
| 音源ファイルを 置く | 著作権と 落とす量。その場で 作れば 0 バイト |
| サーバで 物理を 丸ごと 回す | 8 人 × 60Hz を Durable Object で 回すのは 高い。「あり得るか」の 検算で 十分 |
| 旧 VocabuSurvival を 継ぐ | 別物（2D 横スクロール中心）。継ぐより 建てる ほうが 速く、既存も 壊さない |
| 対戦で 自分の 単語帳を 使う | 相手の 端末から 引けない。自分だけ 自分の 単語・相手は 内蔵に なり、同じ 勝負に ならない |
| かぶりものに 性能を 付ける | 「この 帽子が 強い」に なり、全員 同じ 帽子に なる |
| 中間地点を **足して** 増やす | 8m ぶん 後ろが ずれ、時間で 動く 仕掛けの 位相が 変わって 3 本 通れなく なった（実測 27/30）。飾りの 無い PW を その場で 置き換えるなら 形が 変わらない |
