### 2026-08-28 01:15–01:25 — Phase 0

調べて 分かったこと:

- `package.json` が **無い**。npm test / lint / build は 存在しない。
  検査は ルートの `*.cjs` を node で 走らせる（Playwright は node_modules にある）。
- 本番の 出し方は `server/` から `npx wrangler deploy`。
  `[assets] directory = "../client"` なので **画面も この 1 本で 出る**。
- git 管理下に **無かった** → `git init`（D-06）。
- VocabuSurvival が すでに 3 版 ある（v1 2,050 行 / v2 3,953 行 / v3 2,988 行）。
  **v1 と v2 は `window.BABYLON` を 前提にしているが Babylon.js が どこにも無い**。
  つまり 起動しても 例外で 止まる。画面は Error 2800 で 塞がれている。
- 左パネルは `/api/flags/effective` が 返す 表で 描く（`vq-shell.js` の SEED は 控え）。
  すでに `survival` の 行が あり `tab:survival3` を 指している。
- 認証は `window._authGetToken()`。API の 根は `window.VQ_API_BASE`。
- 対戦の 下地が すでに ある（`RealtimeRoom` / `RoomDO` の Durable Object）。
