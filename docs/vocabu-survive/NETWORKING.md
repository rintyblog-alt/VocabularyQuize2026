# 通信

## 何を どこで 決めるか

| こと | 決めるのは | 理由 |
|------|-----------|------|
| 自分の 位置 | **自分の 端末** | サーバの 返事を 待つと 反応が 鈍くて 遊べない |
| 他人の 位置 | サーバが 配る | 各自が 勝手に 計算すると 全員 違う 絵に なる |
| クイズの 正誤 | **サーバ** | 画面の 判定を 信じると 書き換えれば 全問 正解に できる |
| 出す 問題 | **サーバ** | 全員 同じ 問題で ないと 公平に ならない |
| ゴールの 可否 | **サーバ** | 走らずに 「ゴールした」と 言えては いけない |
| XP | **サーバ** | 画面の 申告を 足すと いくらでも 増やせる |

## 形

やりとりの 形は `client/assets/vocabu-survive/net/proto.js` の **1 枚だけ**。
サーバも 画面も ここを 見る。片方だけ 直すと
「繋がるのに 何も 起きない」という 一番 分かりにくい 壊れ方に なる。

### 画面 → サーバ

| 名 | 中身 | いつ |
|----|------|------|
| `ping` | `{ts}` | 2.5 秒ごと |
| `ready` | `{v}` | 準備を 押した とき |
| `color` | `{v:0..7}` | 色を 選んだ とき |
| `course` / `mode` | `{id}` / `{v}` | **部屋主だけ** |
| `start` | `{length}` | **部屋主だけ**。length は 検算に 使う |
| `in` | `{seq, s:{x,y,z,yaw,g,st,pr,cp,rs}}` | **20Hz** |
| `gate` | `{g, a}` | 門で 答えた とき。**正誤は 送らない** |
| `fin` | `{}` | ゴールした とき |

### サーバ → 画面

| 名 | 中身 |
|----|------|
| `welcome` | 自分の id・部屋・（試合中なら）問題 |
| `room` | 部屋の ようすが 変わった |
| `go` | 合図。`startAt`（サーバの 時刻）・種・コース・問題 |
| `snap` | `{ts, ps:[…]}` **15Hz・変わった 人だけ** |
| `gate` | 自分の 答え合わせ（`c` 正誤・`a` 正解の 番号） |
| `pgate` | ほかの 人が 門を 通った |
| `fin` / `end` | ゴール / 全部 終わり |
| `fix` | 「その 位置は あり得ない」。サーバの 値へ 戻す |

## 減らす 工夫（要件 20）

| 工夫 | 実際に していること |
|------|-------------------|
| 送る 回数を 減らす | 入力は 20Hz、配るのは 15Hz。毎フレーム（60Hz）送らない |
| 変わっていない 人を 送らない | `dirty` の 立った 人だけ `snap` に 入れる |
| 数を 丸める | 位置は 小数 2 桁、進みは 1 桁。文字数が 3 割 減る |
| 入れない ものは 入れない | 速度は 送らない（見た目は 位置の 差から 作れる） |
| 見えない 人 | 遠い 人も 送る（順位表に 要る）。ただし 位置の 精度は 同じ |

## なめらかに 見せる

- **自分**: 自分の 端末で そのまま 動かす（client prediction）。
  サーバが `fix` を 返した ときだけ その 値へ 直す（reconciliation）。
- **他人**: 届いた 位置を **110ms 遅らせて** 前後 2 つの 間で 混ぜる（interpolation）。
  遅らせないと、届いた 瞬間に カクッと 飛ぶ。
- **外挿は しない。** 届いていない 先を 予想して 動かすと、
  壁を すり抜けた ように 見えて かえって おかしい。

## ずるを 止める（要件 22）

`server/src/survive.js` の `_onInput` / `_onFinish`。

| 見るもの | やり方 | 外れた とき |
|---------|--------|-----------|
| 速さ | 前の 知らせからの 距離 ≦ 8.2×1.34 m/s × 経過 ＋ 1.6m | 受け付けず `fix` を 返す |
| 瞬間移動 | 同上（大きく 飛ぶと 引っかかる） | 同上 |
| 進み | 進みの 増分も 同じ 上限で 見る | 同上 |
| 中間地点 | 1 つ 以上 飛ばせない | 数えない・怪しさを 足す |
| ゴール | 進みが 9 割 以上 ＋ 経過が 最速の 75% 以上 | ゴールに しない |
| クイズ | **答えは サーバが 持つ**。番号だけ 受ける | 正誤は サーバが 決める |
| 二度答え | 同じ 門は 1 回だけ | 無視 |
| 部屋の 権限 | コース変更・開始は 部屋主だけ | 無視 |

### 実測で 直した 落とし穴

**最初の 1 通を 弾いていた。**
出発の 並びは 人ごとに 横へ 最大 ±7m ずれている のに、
サーバは 0 を もとに 速さを 見ていた。
x=2 から 出発した 人は 1 通目で 「瞬間移動」と 判定されていた。
→ **最初の 1 通は 基準として そのまま 受ける。**

## 切れた とき（要件 21）

- 切れても 試合は 続く。その 人は 25 秒 「幽霊」として 残る。
- 戻ってきたら 同じ id で 入り直せる（進みも 順位も そのまま）。
- 画面側は 3 回まで 自動で 繋ぎ直す（0.4 秒 → 0.8 秒 → 1.6 秒）。
- 部屋に 誰も いなくなったら 配るのを 止める（Durable Object が 眠る）。

## 検査
