## 4. 人が見る項目（**ここは機械で確かめられていません**）

### 4-1. 最優先：「新しい会話」ボタン

長時間の自動操作のあと、**2 枚目のタブ**で押しても会話が切り替わらないことがありました。

- まっさらな状態では**毎回正常**（1 タブ・2 タブ目・84 会話まで増やして 40 回連打、すべて OK）
- **原因を特定できていません。** 自動操作に固有の可能性が高いが、断定できない
- 同じ失敗が 3 回続いても根本原因が分からなかったので、
  当てずっぽうで直さず**未解決のまま報告**します

**手で見てほしいこと**: 普段どおり何度か会話したあと、別タブを開いて「新しい会話」を押す。
切り替わらなければ、そのときの操作手順を控えてください。

### 4-2. 紙面（印刷）

- 実際のプリンタへの出力は**していません**。印刷ダイアログまでしか見ていない

- Typst と LaTeX は**未導入**。画面にも「この端末には未導入」と出ます。
  対応済みとは書いていません

### 4-3. AI 採点の甘さ

帯が食い違ったものは **3 回とも全部が甘い方向**でした。辛い方向の間違いは 0 件。
部分点の答案は同じ答案でも最大 37.5% 揺れます。

**矛盾した答案が満点で通ることがあります**（未解決）。

**成績評価には使わないでください。** 学習の補助としてなら使えます。

### 4-5. 解答が選択肢と一致しない設問

（`noCorrectChoice`）。保存は**正しく拒否**されるので誤った試験は出ませんが、
その回は手で直すまで保存できません。使っていて出くわしたら、その頻度を教えてください。

## 6. この夜間作業でやっていないこと

守った制約をそのまま書きます。

- 本番へデプロイしていない
- git を触っていない（push も、履歴の書き換えも、そもそもリポジトリではない）
- 本番 DB・実ユーザーデータ・既存 V1/V2 データを変更していない
- 既存プリセットを削除していない（V1 プリセット 47 件はそのまま）
- 個人ファイルを外部へ送っていない
- 認証情報・秘密鍵・Token をログへ出していない
- 1GB を超えるモデルや大量の外部依存を入れていない
- Ollama と Bridge をインターネットへ公開していない（LAN 内・私有 IP・Origin 制限のまま）
- UI から Ollama を直接呼ぶ経路を足していない（Provider → Bridge → Orchestrator のまま）
- 不具合以外の大規模リファクタリングをしていない
- Mac やプロセスを無理に再起動していない（Bridge のみ、変更反映のため 1 回）
